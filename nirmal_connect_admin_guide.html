Dashboard — என்ன காட்டுகிறது?

  • திட்டங்கள், செய்திகள், நிகழ்வுகள், நடவடிக்கைகள் — நேரடி எண்ணிக்கை

  • தொகுதி சாதனைகள் — சாலைகள், நீர், வேலைவாய்ப்பு, மக்கள் நலன்
  • சமீபத்திய Audit Log — யார் என்ன செய்தார்கள் என்ற பதிவு
  • புகார் வகை மற்றும் மாத வாரியான வளர்ச்சி விளக்கப்படம்

📋புகார் சமர்ப்பிப்பு

  • பெயர், தொலைபேசி, வகை, வார்டு, முகவரி விவரங்கள்
  • 10+ புகார் வகைகள் — சாலை, குடிநீர், மின்சாரம், கல்வி, சுகாதாரம்

  • SMS / WhatsApp உறுதிப்படுத்தல்
  • புகார் ID தானாக உருவாக்கம்

👮அதிகாரி ஒதுக்கீடு

  • ஒவ்வொரு புகாரையும் குறிப்பிட்ட Grievance Officer-க்கு ஒதுக்கலாம்
  • Bulk Assignment — பல புகாரை ஒரே நேரத்தில் ஒதுக்கீடு
  • அதிகாரிக்கு தன் பகுதி புகார்கள் மட்டும் தெரியும்
  • ஒதுக்கப்பட்ட அதிகாரியின் பெயர் புகாரில் பதிவு
  • Officer-wise புகார் புள்ளிவிவரம்

📊நிலை கண்காணிப்பு

  • பல புகார்களை தேர்ந்தெடுத்து நிலை மாற்றம்
